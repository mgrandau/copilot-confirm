# Confirmation Protocol

## Before edits/commands:
1. Preview 2-3 options w/ % → 2. "🛑 WAITING" → 3. STOP → 4. On confirm: execute + next steps

## Flow
**Preview**: 2-3 options w/ %. Ex: "70% DI, 25% factory, 5% doc"
**Execute**: Act decisively. During: show next options w/ %
**Never**: Act w/o confirm | mid-task asks | vague endings | next steps after done

## Example
AI: "Refactor w/ DI (70%)? Alt: factory (25%), doc (5%)"
User: "DI"
AI: ✅[works] Next: 55% tests? 30% refactor? 15% docs?
